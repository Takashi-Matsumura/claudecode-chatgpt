# Claude Code ChatGPT-like Interface

A ChatGPT-like interface built with Next.js, React, and Tailwind CSS that simulates a conversational AI chat application.

![Claude Code ChatGPT Interface]()

## Features

- Chat interface similar to ChatGPT/Claude
- Sidebar with chat history management
- Multiple chat sessions
- Loading states and animations
- Responsive design with collapsible sidebar
- Japanese language interface

## Tech Stack

- Next.js 15 with App Router
- React 19
- TypeScript
- Tailwind CSS

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Development Commands

- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run start`: Start production server
- `npm run lint`: Run ESLint

## Project Structure

- `app/`: Next.js app directory with page components
- `components/`: Reusable UI components
- `lib/`: Utility functions
- `public/`: Static assets

## Current Status

This is a frontend prototype that simulates AI chat interactions. It does not connect to an actual AI backend yet.
